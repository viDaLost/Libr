Librarr Mobile — исправленная веб-версия для телефона

Как установить:
1. Распакуй архив.
2. Загрузи все файлы из папки на GitHub Pages или обычный хостинг.
3. Открой index.html с телефона.

Что исправлено:
- Убраны ошибки API error: 404 на GitHub Pages.
- Поиск больше не обращается к несуществующему /api на статическом сайте.
- Downloads, Wishlist, Library и Settings работают локально в браузере через localStorage.
- Кнопка Download добавляет книгу в локальную библиотеку и список завершённых загрузок.
- Wishlist можно добавлять, искать и удалять.
- Library можно просматривать и фильтровать.
- Добавлен fallback-каталог, поэтому поиск показывает результаты даже если внешний поиск недоступен.

Важно:
Это статическая мобильная сборка. На GitHub Pages нельзя запускать Go-backend, поэтому настоящая серверная загрузка торрентов/интеграции qBittorrent/Prowlarr невозможны без отдельного сервера.

Если у тебя запущен настоящий backend Librarr, открой сайт с параметром:
?backend=1
Тогда приложение снова будет обращаться к серверному API.

Если после замены файлов телефон показывает старую версию:
- обнови страницу несколько раз;
- очисти данные сайта в браузере;
- или открой ссылку с параметром ?v=5.
