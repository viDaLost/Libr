Librarr Mobile Web — готовая веб-версия для телефона

Что внутри:
- index.html — готовая мобильная веб-версия, можно открыть прямо в браузере или загрузить на GitHub Pages/любой хостинг.
- manifest.webmanifest + sw.js + icon.svg — базовая PWA-обвязка, чтобы сайт можно было добавить на экран телефона.

Важный момент:
Исходный архив Librarr — это Go backend + frontend. Без backend обычный index.html не может обращаться к /api/search, /api/downloads, /api/library и т.д. Поэтому в этой сборке я добавил локальный мобильный runtime: поиск, библиотека, избранное, загрузки и настройки работают в браузере через localStorage.

Как запустить:
1. Распакуйте архив.
2. Откройте index.html на телефоне или загрузите все файлы из папки на GitHub Pages.
3. Данные сохраняются в браузере телефона.

Как подключить настоящий backend Librarr:
- Если вы запускаете оригинальный Go-сервер Librarr и хотите использовать реальные API, откройте сайт с параметром ?backend=1.
- Для полноценного поиска/скачивания всё равно нужны серверные настройки Librarr: qBittorrent/SABnzbd, источники, папки библиотеки и т.д.

Примечание:
Для красивого оформления используется Tailwind CDN из исходного проекта, поэтому при первом открытии нужен интернет.
