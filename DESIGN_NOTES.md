# Как использован репозиторий UI UX Pro Max

Я изучил структуру репозитория `ui-ux-pro-max-skill`: skill-файлы, CSV-базы паттернов, цветов, типографики, стилей, UX-гайдлайнов и пример `preview/xiaomaomi-app.html`.

## Принятые решения

### 1. Product reasoning
Запрос относится к категории `Travel/Tourism Agency`, где репозиторий рекомендует storytelling-driven hero, route-first логику, destination colors и сильный CTA выше первого экрана.

### 2. Style
Вместо перегруженного glassmorphism выбран гибрид:

- `Organic Biophilic` — природные формы, мягкие радиусы, зелёные/земляные тона.
- `Nature Distilled` — песочный фон, тёплая курортная фактура, спокойный premium feel.
- Умеренный `Motion-Driven` — reveal-анимации и живая SVG-карта, но с поддержкой `prefers-reduced-motion`.

### 3. Typography
Из рекомендаций для wellness/tourism выбран `Lora + Raleway`:

- Lora — заголовки, курортная редакционная эстетика.
- Raleway — интерфейс, кнопки, карточки и плотная мобильная читаемость.

### 4. UX mechanics
Применены правила из `ux-guidelines.csv`:

- Sticky navigation не перекрывает контент.
- Active state у навигации.
- Touch targets от 44px.
- Минимум 8px между интерактивными элементами.
- Видимый `focus-visible`.
- Модальные карточки имеют явную кнопку закрытия.
- Нет emoji в роли иконок — используются SVG.
- Контент не уходит в горизонтальный скролл.
- Анимации на `transform/opacity`.
- Поддержан `prefers-reduced-motion`.
- Состояния сохраняются: избранные маршруты и тема.

### 5. Information architecture
Сайт построен не как справочник, а как маршрутный сервис:

1. Герой с обещанием пользы.
2. Быстрые действия.
3. Выбор города по настроению.
4. Подбор маршрута.
5. Готовые маршруты.
6. Блок минеральных вод.
7. Практические советы.

Это снижает когнитивную нагрузку на туриста: пользователь сначала выбирает сценарий, а уже потом читает детали.
